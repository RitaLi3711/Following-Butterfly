Materials:
(Actual butterfly)
- some sort of sensor (UWB sensors)  https://github.com/geraicerdas/Cerdas-UWB-Tracker
- Arduino uno mini
-  thin films (PET (Polyethylene Terephthalate))   ... flower wrapping film
- 1mm and 1.5mm Carbon fiber rods
- 2 servors (1 for each wing)
-   Blue Arrow D03013 Digital Ultra-Micro Preision Servo
-   battery ( 2S 180 LiPo Battery (8.4V))

(Clip that sends signals for butterfly to follow)
- UWB tag
